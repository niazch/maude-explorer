Methods and limits

Source. FDA MAUDE medical device reports (download files), cleaned and checked by the pipeline. Counts are distinct reports. Years are years received by the FDA.

2×2 table. For a device type (product code) and a problem code: a = reports with both, b = reports with the device type and another problem code, c = reports with the problem code and another device type, d = all other reports. Only reports with at least one problem code of the selected kind (device or patient) are in the table.

Statistics. ROR with 95% CI (log method). PRR with χ² (Yates). IC with IC025 (BCPNN, simplified formula: IC025 = IC − 3.3(a+0.5)−½ − 2(a+0.5)−3/2). If a cell is 0, the ROR and PRR use a 0.5 correction in each cell. Fisher's exact test, one-sided (more reports than expected), with Benjamini-Hochberg q-values (false discovery rate) over all problem codes in the table; the display filters do not change the q-values.

Limits. MAUDE is a passive reporting system. A report does not show that the device caused the event. The data cannot give incidence rates. One event can have more than one report (manufacturer, user facility, voluntary). Reporting changes with recalls, litigation, summary reporting programs and code changes (for example, the code revisions of 2009 and 2019–2021). A signal is a hypothesis for review, not a conclusion.

            Reporting timeliness

            How long manufacturers took to send their reports to the FDA. The report time is the date the FDA received a report minus the date the manufacturer became aware of the event (field G4 of Form 3500A). FDA regulation requires most manufacturer reports within 30 days. The method follows Everhart et al., BMJ 2025;388:e081518.
